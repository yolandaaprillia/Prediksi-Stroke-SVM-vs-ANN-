1. Mengapa dataset stroke, dan apa masalahnya?

Stroke adalah penyebab utama kematian dan disabilitas. Pada screening, melewatkan pasien berisiko jauh lebih mahal daripada memeriksa ulang pasien sehat. Tetapi data stroke punya masalah klasik: kelas sangat tidak seimbang.

Accuracy paradox

Model yang selalu menjawab tidak stroke sudah benar ±95% kasus. Angkanya bagus, modelnya tidak berguna. Karena itu kita menilai model dengan recall, PR-AUC, dan F2.

2. Apa yang dikatakan data?

Hasil EDA dan uji statistik (Chi-square untuk kategorikal, Mann-Whitney untuk numerik) menunjukkan satu faktor yang mendominasi: usia.

Stroke rate per kelompok usia (%)

Kekuatan asosiasi fitur kategorikal (Cramér's V)

Median usia pasien stroke 71 tahun vs 43 tahun pada pasien tanpa stroke. Gender dan tipe tempat tinggal tidak signifikan (p > 0,05).

3. Bagaimana data diolah dan model bekerja?

  1. CleaningHapus 1 baris gender "Other"; 201 bmi kosong diimputasi median.
  2. Split 80/20 stratifiedProporsi stroke tetap ±5% di data latih dan uji.
  3. Scaling + One-HotSemua di dalam Pipeline agar tidak ada data leakage.
  4. Atasi imbalanceSVM: class_weight. ANN: SMOTE (hanya di data latih).
  5. Tuning 5-fold CVGridSearchCV berbasis ROC-AUC.
  6. Optimasi thresholdMaksimalkan F2 pada prediksi out-of-fold.

SVM

Mencari hyperplane dengan margin terbesar. Kernel RBF memungkinkan batas non-linear. C mengatur toleransi kesalahan, gamma jangkauan pengaruh tiap sampel. Terpilih: C=1, gamma=0,005.

ANN (MLP)

Neuron berlapis yang belajar lewat backpropagation untuk meminimalkan log-loss. Terpilih: 1 layer 16 neuron, alpha=0,1. Regularisasi kuat dibutuhkan karena data kecil.

4. Model mana yang lebih baik?

Perhatikan: pada baseline, accuracy tertinggi, tetapi recall nol.

Confusion matrix (data uji, threshold teroptimasi)

5. Insight utama

Fitur paling berpengaruh (permutation importance)

  • Usia menyumbang hampir seluruh kekuatan prediksi (penurunan AUC ±0,30 vs <0,04 fitur lain).
  • SVM lebih stabil: gap AUC train-test 0,011 vs ANN 0,108, tanda ANN lebih mudah overfit pada 249 kasus positif.
  • Trade-off nyata: precision ±15%, artinya ±5-6 alarm palsu per stroke yang terdeteksi. Cocok untuk screening, bukan diagnosis.
  • Asosiasi bukan kausalitas: banyak fitur lain tercampur dengan usia.

Keterbatasan

Hanya 50 kasus stroke di data uji, sehingga interval kepercayaan lebar. SMOTE dijalankan setelah one-hot encoding. Model dibuat untuk pembelajaran, bukan penggunaan klinis.
